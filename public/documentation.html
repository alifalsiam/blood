LifeDrop Emergency Blood Donation Platform

A complete, end-to-end architectural and functional manual detailing the real-time matching engine, donor availability stream, receiver discovery radar, administrative governance, and hybrid persistence layers.

📌 1. Executive Summary & Vision

LifeDrop is a mission-critical web platform designed to eliminate fatal delays during medical emergencies by instantly bridging blood seekers (Receivers) and compatible, eligible donors across all 8 divisions and 64 districts in Bangladesh.

⚡

Sub-Minute Matching

Connects critical patients with verified donors via geographic proximity radar and direct notification pings.

🛡️

Verified Registry

Authenticates blood groups, contact numbers, donation intervals, and administrative identity credentials.

🔄

Zero-Lag Real-Time

Employs Server-Sent Events (SSE) and Supabase Postgres CDC streams for live status and admin synchronization.

🏗️ 2. High-Level Architecture

LifeDrop utilizes a resilient Hybrid Persistence & Real-time Synchronization Architecture. Client state is backed simultaneously by an Express Node.js micro-service, Supabase PostgreSQL, and local browser persistence.

🩸 4. Donor Workflow & Life Cycle

1. Enrollment & Medical Clearance

Donors register with blood group (e.g. O+, A-, AB+), weight (>45kg), sex, division, and emergency contact. Eligibility algorithms automatically verify medical constraints.

2. 90-Day Cooldown Tracker

Enforces national safety standards requiring a 3-month gap between whole blood donations with automated countdown timers.

3. Emergency Alert Stream

Donors view urgent patient requests sorted by geographic proximity and match affinity. One-click readiness notifies the requester immediately.

4. Digital Cryptographic Card

Generates a verifiable donor passport with donation milestones (Bronze, Silver, Gold, Platinum) and downloadable PNG/JPG cards.

🚨 5. Receiver (Emergency Seeker) Workflow

The 3-Step Emergency Fulfillment Pipeline

  1. Create Urgent Request: Input patient name, hospital, units needed, urgency status (Critical / Immediate), and coordinate location.
  2. Live 25km Discovery Radar: Interactive visual radar scans registered donors in real-time, displaying distance, verified rating, and contact state.
  3. Approved Contacts & Flyer Generator: Contact approved donors directly and generate instant hospital posters for WhatsApp & Facebook groups.

🔄 7. Real-Time Synchronization Engine

LifeDrop eliminates stale data issues by establishing a bidirectional synchronization matrix between administrators and connected users:

[Admin modifies User/Bank/Config] │ ├──► 1. Writes to Express API (/api/users) ├──► 2. Writes to Supabase Database (profiles table) ├──► 3. Server-Sent Events (SSE) triggers 'users_updated' event │ ▼ [Active User Session (AuthContext)] │ ├──► Catches SSE broadcast OR Supabase Realtime postgres_changes ├──► Automatically updates local React state without page refresh └──► If banned or suspended, immediately logs out user and alerts them.

🗄️ 8. Database Schema Reference

The Supabase PostgreSQL database implements strict Row-Level Security (RLS) and structured constraints:

Table Key Columns Security / Access
public.profiles id (uuid), user_id (text), full_name, email, phone, blood_group, division, district, status, verified, total_donations Public Read; Authenticated User Write on own record; Full Admin Override.
public.blood_banks id, name, division, district, phone, address, available_groups, verified Public Read; Admin Write.
public.blood_requests id, patient_name, hospital_name, blood_group, units_needed, urgency, status, created_at Public Read; Requester & Admin Manage.
